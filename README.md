SMART ATTENDANCE CALCULATOR:
A dual-mode student attendance calculator developed to help students monitor their attendance and plan their future attendance effectively.

ABOUT THE PROJECT:
Smart Attendance Calculator is a web-based application that calculates attendance percentage using either working days or individual classes. It also helps students understand how many more classes they can miss and how many consecutive classes they need to attend to reach the required attendance percentage.

FEATURES:
 *Dual-mode calculation: Working Days and Individual Classes.
 *Calculates current attendance percentage.
 *Predicts the maximum number of additional absences allowed.
 *Calculates the number of consecutive classes required to recover attendance.
 *Predicts attendance percentage after planned absences.
 *Displays attendance status and warnings.
 *Simple and responsive user interface.

TECH STACKS:
 *HTML
 *CSS
 *JavaScript

HOW TO RUN:
1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Enter your attendance details and click Calculate.
